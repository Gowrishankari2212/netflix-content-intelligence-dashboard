# 🎬 Netflix Content Intelligence Dashboard

## 📊 Project Overview

Netflix Content Intelligence Dashboard is an interactive Tableau project designed to explore and analyze Netflix movies and TV shows.

The dashboard provides insights into content distribution, genres, ratings, countries, release years, and the comparison between Movies and TV Shows.

link:https://public.tableau.com/app/profile/gowri.shankari1922/viz/NetflixDashboard__17903117976960/Dashboard2?publish=yes

## 🎯 Objectives

- Analyze Netflix content trends over time
- Compare Movies and TV Shows
- Identify popular content ratings
- Analyze content distribution by country
- Explore top genres
- Understand TV Show season distribution
- Identify changes in Netflix content over the years

## 💡 Key Insights

- Netflix contains both Movies and TV Shows across a wide range of genres.
- Content distribution varies significantly by country.
- TV-MA is one of the major content ratings in the dataset.
- Netflix content increased substantially in recent release years.
- Movies and TV Shows show different distribution patterns.


## 📌 Dataset

The project uses the Netflix Titles dataset containing information about movies and TV shows available on Netflix.
